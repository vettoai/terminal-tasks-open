# L3 3DX diagnostics screen

The generator presents these readings in a fixed arrangement. Inspection templates can put the fields in a different order.

The single-column screen runs from top to bottom:

1. Coolant outlet pres
2. X-Ray tube filament
3. X-Ray beam current
4. HV modulation
5. X-Ray High voltage
6. +12V supply
7. –12V supply
8. +24V supply
9. -24V supply
10. +149V / +140V supply
11. +6.5V supply
12. +2.5V reference
13. Digital input
14. Multiplex input
15. Anode IGBT temp
16. Cathode IGBT temp

The two-column screen has eight rows, read down each panel:

| Left panel | Right panel |
| --- | --- |
| Coolant outlet pres | -24V supply |
| X-Ray tube filament | +149V / +140V supply |
| X-Ray beam current | +6.5V supply |
| HV modulation | +2.5V reference |
| X-Ray High voltage | Digital input |
| +12V supply | Multiplex input |
| –12V supply | Anode IGBT temp |
| +24V supply | Cathode IGBT temp |

The positive and negative 12V supplies are separate readings, as are the positive and negative 24V supplies. Anode and Cathode temperatures also refer to different parts of the generator.
